# Drum Kit Web Application

An interactive drum machine built with HTML, CSS, and JavaScript. 
Users can play drum sounds using keyboard keys or on-screen buttons, 
with real-time audio playback and smooth animations.

## Features
- Keyboard and mouse/touch support
- Real-time audio feedback for each instrument
- Smooth button animations on trigger
- Responsive UI design

## Tech Stack
HTML · CSS · JavaScript
